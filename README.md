# 🌟 Sistema Empresarial El Ceibo

Sistema web de gestión empresarial desarrollado con React + TypeScript + Tailwind CSS, diseñado para mejorar la administración de procesos internos como capacitación, objetivos, indicadores KPI y reportes.

---

## 📊 Descripción

Este sistema permite centralizar la información empresarial para facilitar la toma de decisiones y el seguimiento del desempeño organizacional en tiempo real.

---

## 🚀 Funcionalidades

### 👤 Gestión de usuarios
- Roles de administrador y empleado
- Perfiles personalizados
- Control de acceso por tipo de usuario

### 📚 Capacitación
- Registro de cursos
- Seguimiento de empleados
- Evaluación de desempeño

### 📈 Gestión estratégica
- Objetivos empresariales
- Control de progreso
- Indicadores de cumplimiento

### 📊 KPI
- Métricas de rendimiento
- Visualización de datos
- Análisis empresarial

### 📄 Reportes
- Historial de información
- Reportes internos
- Seguimiento de procesos

---

## 🎯 Objetivo

Mejorar la eficiencia empresarial mediante una plataforma digital que permita:

- Toma de decisiones basada en datos
- Control del desempeño del personal
- Centralización de la información
- Optimización de procesos internos
